# Notion 데이터베이스 설계서 — 계약 관리

이 문서는 계약봇이 데이터를 적재할 Notion 데이터베이스(이하 "DB")의 구조와
생성 절차를 정의합니다. 비개발자도 이 문서대로 따라 만들면 n8n 워크플로가
바로 연동됩니다.

---

## 1. 새 데이터베이스 만들기

1. Notion에서 계약을 보관할 부모 페이지를 하나 만듭니다 (예: "회사 운영 / 계약").
2. 부모 페이지 본문에서 `/database` 입력 → **Database - Full page** 선택.
3. DB 이름을 **"계약 관리"** 로 지정합니다.

> 한 계약 건은 이 DB의 **한 행(Page)** 으로 들어갑니다.

---

## 2. 컬럼(Property) 정의

기본 생성 시 들어 있는 `Name` 컬럼은 **"거래처명"** 으로 이름만 바꾸세요
(타입은 그대로 Title 유지). 그 외 컬럼은 새로 추가합니다.

| 컬럼명 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 거래처명 | Title | ✓ | 기본 Name 컬럼을 이름만 변경 |
| 서비스명 | Text | ✓ | |
| 계약목적 | Text | | 여러 줄 가능 |
| 계약시작일 | Date | ✓ | |
| 계약종료일 | Date | ✓ | 캘린더 뷰의 기준이 됨 |
| 견적비용 | Number | | Format: **₩ Won** |
| 등록 담당자 | Text | ✓ | Slack User ID 저장 (예: `U01ABCDEFGH`) |
| 업무 담당자 | Text | ✓ | Slack User ID |
| 추가 알림 대상 | Text | | 콤마 구분 Slack User ID 목록 |
| 갱신 알림일 | Date | | 이날 09:00에 알림 발송 |
| 거래처 통지일 | Date | | 거래처에 통지해야 하는 날 (선택) |
| 상태 | Select | | 옵션: `진행중`, `만료임박`, `만료`, `갱신완료` |
| Slack 등록 메시지 | URL | | 모달이 제출된 Slack 메시지 링크 (자동 채움) |

> **중요**: 컬럼 이름은 위 표와 정확히 동일해야 n8n 워크플로의 매핑이
> 동작합니다. 띄어쓰기·맞춤법까지 그대로 따라 주세요.

### Select 옵션 미리 만들기

`상태` 컬럼의 옵션 4개(`진행중`/`만료임박`/`만료`/`갱신완료`)는 미리
한 번씩 입력해 두세요. 그래야 n8n에서 옵션 값을 안전하게 사용할 수 있습니다.

---

## 3. 뷰 4개 만들기

DB 좌상단 `+ Add view` 버튼을 사용해 다음 뷰들을 추가합니다.

### 뷰 1. 테이블 뷰 (기본, 이미 있음)
- 이름: **전체 목록**
- 정렬: `계약종료일` 오름차순
- 보일 컬럼: 거래처명, 서비스명, 계약시작일, 계약종료일, 상태, 업무 담당자

### 뷰 2. 캘린더 뷰 — 계약 종료 기준
- `+ Add view` → **Calendar** 선택
- 이름: **만료 캘린더**
- Calendar by: `계약종료일`
- 용도: 어떤 달에 어떤 계약이 만료되는지 한눈에

### 뷰 3. 캘린더 뷰 — 알림일 기준
- `+ Add view` → **Calendar** 선택
- 이름: **알림 캘린더**
- Calendar by: `갱신 알림일`
- 용도: 언제 누구에게 알림이 갈지 미리 시각적으로 확인

### 뷰 4. 보드 뷰 — 상태별
- `+ Add view` → **Board** 선택
- 이름: **상태 보드**
- Group by: `상태`
- 용도: 진행중/만료임박 등 상태별 워크플로

## 4. Notion Integration 연결

n8n이 이 DB에 글을 쓰려면 Notion Integration을 만들고 DB에 연결해야 합니다.

### 4-1. Integration 생성
1. https://www.notion.so/my-integrations 접속
2. **+ New integration** 클릭
3. 이름: `계약봇 n8n`
4. Associated workspace: 본인 워크스페이스
5. Type: **Internal**
6. **Save** 클릭
7. 다음 화면에서 **Internal Integration Secret** 을 복사 → 안전한 곳에 보관
   (이 값이 `NOTION_TOKEN`)

### 4-2. DB에 Integration 연결
1. "계약 관리" DB 페이지 우상단 **`···`** 메뉴 클릭
2. **Connections** → 방금 만든 `계약봇 n8n` 검색해 추가
3. 권한 확인 다이얼로그가 뜨면 **Confirm**

> 이 단계를 빼먹으면 n8n이 401/404 에러를 냅니다. 가장 흔한 실수입니다.

## 5. Database ID 추출

n8n에 알려줘야 하는 또 하나의 값입니다.

1. "계약 관리" DB 페이지 우상단 **Share** → **Copy link** 클릭
2. 복사된 URL 형태:
   ```
   https://www.notion.so/myworkspace/계약-관리-1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p?v=...
   ```
3. URL에서 물음표(`?`) 앞에 있는 **마지막 32자리 영숫자** 가 Database ID:
   ```
   1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p
   ```
4. 이 값이 `NOTION_DATABASE_ID`. n8n Credentials에 저장합니다.
